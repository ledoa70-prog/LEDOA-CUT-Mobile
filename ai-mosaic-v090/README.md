# LEDOA 모자이크 v0.9.1

v0.8.6.4 AI 얼굴 추적 앱을 기반으로 만든 네이티브 모자이크 편집기입니다.
v0.9.1은 독립 패키지 `kr.ledoa.cut.mosaic`로 설치됩니다. 기존 AI 추적 앱과 LEDOA CUT 본앱을 삭제하거나 덮어쓰지 않습니다. 이전 앱의 작업 데이터가 자동으로 이동되지는 않습니다.

v0.9.0의 설치 실패는 기존 v0.8.6.4와 같은 패키지 ID에 서로 다른 인증서를 사용한 것이 원인입니다. 실제 v0.8.6.4 인증서는 `bb03460b…237c490`, v0.9.0은 `4b31f623…64740f`이며, 보관된 키로 기존 인증서를 복구할 수 없어 독립 설치로 변경했습니다. v0.9.1부터는 키 경로를 명시하고 인증서 SHA-256을 빌드에서 검사합니다.

## 사용법
1. 영상 열기 → 휴대폰 영상 선택
2. 한 사람만 가릴 때는 **선택 얼굴**에서 얼굴을 터치합니다. 검출되지 않은 얼굴은 **직접 영역 지정**으로 드래그합니다.
3. 모든 사람을 가릴 때는 **전체 얼굴**을 선택합니다.
4. **자동 추적**을 누릅니다. 강도와 얼굴 여백은 다시 분석하지 않고 조정할 수 있습니다.
5. 소리와 함께 재생합니다. 색상 막대에서 초록은 위치가 있는 구간, 빨강은 선택 얼굴의 위치가 없는 구간, 노랑은 자동 보완 또는 확인 구간, 흰 세로선은 검출된 장면 경계입니다.
6. 누락된 곳은 **다음 확인 구간**으로 이동합니다. 선택 얼굴 모드에서 얼굴을 다시 터치하고 자동 추적하면 앞쪽 결과를 남기고 뒤쪽을 다시 분석합니다.
7. **MP4 저장** → 저장 위치 선택. H.264 영상과 원본 AAC 오디오가 저장됩니다.

처음 얼굴을 영상 중간에서 선택하면 그 시점부터 적용됩니다. 구간·진단 메뉴의 현재부터/현재까지/전체 구간으로 범위를 변경할 수 있습니다.

## 달라진 점
- 터치 얼굴 선택, 전체 얼굴 모드, 강도·여백 슬라이더, 큰 미리보기, 접을 수 있는 구간·진단 메뉴.
- 선택 얼굴은 OpenCV SFace INT8 128차원 특징을 사용합니다. 기존 색·명암 비교를 실제 편집 경로에서 교체했습니다.
- 장면 전환 시 이전 움직임 상태를 초기화합니다. 동일 인물 후보를 3개의 검출 시점에서 확인하며, 실제로 검출된 앞쪽 후보 위치를 보완합니다.
- 전체 얼굴 모드는 신원을 매칭하지 않고 새 장면의 얼굴들을 다시 검출합니다.
- 640px AI 프레임과 224px 중간 움직임 프레임을 순차 처리합니다. 반복적인 전체 해상도 픽셀 읽기 비용과 불필요한 몸통 추론을 제거했습니다.
- MediaPlayer/OpenGL 소리 재생과 MediaCodec/OpenGL MP4 내보내기를 추가했습니다. 얼굴 좌표·모자이크 셰이더를 공유합니다.
- 원본 영상과 얼굴 특징은 서버에 전송하지 않습니다. 앱은 INTERNET 권한이 없습니다. 얼굴 특징은 작업 중 메모리에서만 사용하고 진단 파일에는 포함하지 않습니다.

## 지원 범위와 확인 필요 사항
- 자동 검출은 얼굴 가림, 심한 옆얼굴, 빠른 움직임, 작은 얼굴에서 누락될 수 있습니다. 같은 인물이라는 근거가 약하거나 비슷한 후보가 여럿이면 확인 구간으로 남깁니다.
- 분석은 기본 100ms 간격이며 중간 위치를 보간합니다. 모든 프레임에서 검출 성공을 보증하지 않습니다.
- 최대 한 화면 32개 얼굴. 출력은 긴 변 최대 1920px. 원본 타임스탬프를 유지하므로 입력이 가변 프레임이면 출력도 가변 간격입니다.
- HDR 저장과 AAC 이외의 오디오 변환은 이번 버전에서 지원하지 않습니다. 지원하지 않는 소스는 저장 오류로 알리고 무음 결과로 바꾸지 않습니다.
- 분석 완료 전·중단된 결과는 MP4 저장이 비활성화됩니다. 저장 중 취소하면 임시 파일을 제거합니다.
- 구간 바깥은 원본 화면을 유지합니다. 영상 전체를 재생해 확인한 후 공유하세요.

## 검증
`bash run-tests.sh`는 현재 정책의 추적·오인물 방지·장면 전환·복수 얼굴·구간 경계 회귀 검사를 수행합니다.
과거 0.7.2/0.8.0/0.8.2의 일부 테스트는 구버전(600ms 광학추적 등) 정책을 검증하므로 현재 실행 목록에 포함하지 않습니다. 테스트를 조작하여 성공으로 바꾸지 않았습니다.
Android instrumented 검사는 실제 모델의 특징 추출, 얼굴 검출/재생 화면, MP4 픽셀 변화·오디오·길이·회전·취소를 확인합니다.
사용자 Fold6의 실제 동작과 처리 속도는 별도 확인이 필요합니다. 첨부한 34.774초 MP4는 다른 편집기 사용 예시이며, 추가한 18.594초 원본은 로컬 검증에 사용합니다. 원본 영상은 공개 저장소나 빌드 서버에 업로드하지 않습니다.

원본에 대한 보조 검사에서는 YuNet 검출 + 동일한 SFace 모델 + 앱의 Java 추적/장면/광학 보완 코드를 실행했습니다. 기존 기록에서 다른 사람에게 옮겨갔던 약 12초 구간을 거부하고, 원래 대상이 재등장한 13.3초부터 실제 검출 위치를 다시 연결했습니다. 이 검사는 Android ML Kit 검출 결과나 Fold6의 실측 속도를 대신하지 않습니다.
